# Buku Tani — pembukuan usaha tani (Android, offline)

Aplikasi pembukuan untuk petani anggota kelompok tani: biaya per musim tanam, panen, penjualan, utang kios,
untung rugi, R/C ratio, BEP, dan perbandingan antar musim/lahan. Tanpa akun, tanpa iklan, tanpa internet.

- Unduh APK terbaru: https://github.com/rokhmanpermadi-jpg/bukutani/releases/latest/download/BukuTani.apk
- Versi web (PWA): folder `docs/` disajikan lewat GitHub Pages.
- Aplikasi web ada di `app/src/main/assets/www/` (APK) dan `docs/` (PWA); keduanya harus sama.
